# Store (vitrina /store) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Exponer la URL pública `/store/` estilo Marketplace con todos los productos del POS y existencias exactas en tiempo real.

**Architecture:** Dos endpoints públicos sin login (`/store/` server-render + `/store/api/estado/` JSON con polling cada 20 s); la fuente de stock es la misma del POS (`Producto.stock`, o suma de `AlmacenStock` en `multi_pos`).

**Tech Stack:** Django 5.2 templates + CSS propio con tokens DESIGN.MD (sin dependencias nuevas); tests con `django.test.TestCase`.

**Spec:** `docs/superpowers/specs/2026-10-13-store-design.md`

## Global Constraints

- Solo vitrina con stock: sin carrito, sin compra, sin pedido, sin pago.
- Sin login en `/store/` y `/store/api/estado/`; solo GET; nunca exponer `precio_compra`, `stock_minimo` ni proveedor.
- Convive con `/catalogo`: no modificar ni redirigir `catalogo.html`, `base.html`, `static/css/styles.css` ni `DESIGN.MD`.
- Estilos: tokens DESIGN.MD (`--accent #6f53d9`, `--bg #f7f7fb`, `Inter` + `JetBrains Mono`); llave dark `bizm_theme`.
- Polling del API cada 20 s; ante fallo se conserva la última data con dot rojo.
- Límite v1: hasta 2000 productos por respuesta.

## Review Focus

- Producto con `activo=False` o (en modos simples) `visible_pos=False` no debe aparecer en `/store/` aunque tenga stock.
- En `multi_pos` el stock mostrado debe ser la suma de todos los `AlmacenStock` del producto, no `Producto.stock`.
- El JSON del API no debe contener las claves `precio_compra`, `stock_minimo` ni `proveedor` bajo ningún modo.
- Un producto con imagen rota o sin imagen debe mostrar iniciales en mono, sin `<img>` roto ni 500.
- Con el API caído (500/timeout), la página debe seguir mostrando la última data con aviso "Sin conexión", sin vaciar el grid.

```python
from decimal import Decimal
from django.test import TestCase
from django.urls import reverse
from .models import Producto, Categoria, Almacen, AlmacenStock, ConfiguracionTienda

class StoreTest(TestCase):
    def test_store_publico_sin_login_muestra_stock_exacto(self):
        Categoria.objects.create(nombre='Viveres')
        Producto.objects.create(nombre='Arroz', unidad_medida='unidades',
            precio_compra=10, precio_venta=20, stock=Decimal('12'))
        Producto.objects.create(nombre='OcultoNoVisible', unidad_medida='unidades',
            precio_compra=1, precio_venta=2, stock=Decimal('9'), visible_pos=False)
        Producto.objects.create(nombre='OcultoInactivo', unidad_medida='unidades',
            precio_compra=1, precio_venta=2, stock=Decimal('9'), activo=False)
        r = self.client.get(reverse('core:store'))
        self.assertEqual(r.status_code, 200)
        self.assertContains(r, 'Arroz')
        self.assertContains(r, '$20')
        self.assertContains(r, '12')
        self.assertNotContains(r, 'OcultoNoVisible')
        self.assertNotContains(r, 'OcultoInactivo')

    def test_store_api_no_expone_costos(self):
        Producto.objects.create(nombre='Frijol', unidad_medida='unidades',
            precio_compra=99, precio_venta=20, stock=Decimal('5'))
        r = self.client.get(reverse('core:store_api'))
        self.assertEqual(r.status_code, 200)
        body = r.json()
        self.assertIn('productos', body)
        payload = str(body)
        self.assertNotIn('precio_compra', payload)
        self.assertNotIn('stock_minimo', payload)

    def test_store_api_multi_pos_suma(self):
        cfg = ConfiguracionTienda.get_solo()
        cfg.modo_operacion = 'multi_pos'
        cfg.save(update_fields=['modo_operacion'])
        a1 = Almacen.objects.create(nombre='A1')
        a2 = Almacen.objects.create(nombre='A2')
        p = Producto.objects.create(nombre='Azucar', unidad_medida='unidades',
            precio_compra=5, precio_venta=10, stock=Decimal('0'))
        AlmacenStock.objects.create(producto=p, almacen=a1, cantidad=Decimal('5'))
        AlmacenStock.objects.create(producto=p, almacen=a2, cantidad=Decimal('7'))
        r = self.client.get(reverse('core:store_api'))
        item = [x for x in r.json()['productos'] if x['id'] == p.id][0]
        self.assertEqual(Decimal(item['stock']), Decimal('12'))
```
